# Azure Databricks

- It is an Apache Spark-based analytics platform optimized for the Microsoft Azure cloud service platform
- It is designed to simplify the process of building big data and AI solutions
- Provides an unified analytics platform that accelerates the preparation of data for analytics and machine learning
- Key fetures:
    - Collaborative Environment: shared workspaces for collaboration among data engineers
    - Azure Integration: integrates with Data Factory, Synaps Analytics, Machine Learning and Power BI
    - Apache Spark Integration: serverless Apache Spark experience with auto-configuration and integrated Azure security
    - Auto-Scaling and Performance
    - Robust Security: AD integration, role-based access control, private network connectivity and industry-standard compliance
- Use cases:
    - Big data analytics
    - Machine Learning: provides a platform for preparing, developing, training and deploying MI models
    - Real-time analytics: Databrics supports streaming analytics
    - ETL processess
    - Data exploration and visualization: the collaborative workspace can bae used for data visualization
- Azure Databricks vs Azure Data Factory:
    - Azure Databrics focues on big data and MI
    - Azure Data Factory primarly handles data integration and pipeline orchestration in the cloud
